This update includes general combat balancing, new/updated weapons, and more juicy stuff!

## Changelog
* Updated the security armoury visuals for the `AA-12`, `FN P90`, `HK416`, `KRISS Vector`, and `R870`.
* Updated the Winchester's scope overlay, reducing the visibility of the glass scratches.
* Moved the `M4A1-S` inside the primary security armoury to the dedicated squadrons section.
* Improved the coverage of teleport bricks inside the security headquarters.
* Removed an unfinished concept weapon that was not intended to make it into the release version.
* Fixed dynamic heads, again. ([#R0952](<https://discord.com/channels/939956361977020449/1505281485433995354>))
* Fixed a bug where the teleportation device was sometimes broken. ([#R0961](<https://discord.com/channels/939956361977020449/1505482907110871141>))
* Fixed a bug where raiders could not pick up the `AKM` or `L1A1` if they only owned Tier 3. ([#R0955](<https://discord.com/channels/939956361977020449/1505399047077494905>))
* Fixed the security requirements for the `AA-12`, `FN P90`, and `M4A1-S` not being as intended.
* Fixed the security requirements for the remote blast door controls not being as intended.
* Fixed the `M4A1` inside the secondary security armoury having a debug billboard.
* Fixed the sounds for the `AK-74`, `AKM`, `M4`, `M4A1`, `M4A1-S`, and `RPK` not being as intended.
