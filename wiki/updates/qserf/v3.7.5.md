QSERF v3.7.5 is the fifth patch following [v3.7.0](/wiki/updates/qserf/v3.7.0), fixing various issues.

## Changes
* Adjusted certain teleport brick positions.
* Character limbs now collide with the world when ragdolled.
* Reduced the maximum power at which grenades can propel you by 300%.
* The admin command box is now hidden by default.
* The sliding door override lever can now be used by those on the admin team.

## Fixes
* Fixed a bug where gun recoil was framerate-dependent, resulting in a lower FPS producing less recoil, and vice-versa.
  * You might notice that recoil feels different after this change, however it should now be more consistent and closer to as intended, but we'll adjust these values if necessary.
* Fixed a bug where gun recoil was effectively paused when un-equipping, and later resumed when re-equipping.
* Fixed a bug where you could get stuck in the "landed" state when getting stunned on the same frame as entering said state.
  * This caused a rare issue where your character would slide across the floor uncontrollably until the stun ended.
* Fixed a bug where character effects with an expiry would cause an error when they expire while more than one effect is present. ([#0496](<https://discord.com/channels/939956361977020449/1395880779606659205>))
  * This caused a rare issue where getting stunned twice would effectively leave you stunned permanently.
* Fixed a bug where the character would remain crouched while ragdolled.
* Fixed a bug where an error would occur when jumping while crouched.
* Fixed a bug where the christmas radio would not preserve its muted state after leaving the area.
* Fixed a bug where blast doors would temporarily get stuck if regen occurred during intruder alert.
* Fixed a bug where security camera #22 was missing. ([#0380](<https://discord.com/channels/939956361977020449/1362838553788153857>))
* Fixed a bug where you could fall into the void when exiting security cameras.
* Fixed a bug where the visual state of security cameras wasn't always accurate.
* Fixed a bug where when exiting security cameras, the camera you were on would remain invisible.
* Fixed a bug where bullets would not penetrate the leaves of `prop_plant_generic_c`.
* Fixed a bug where players outside elevators could be teleported with it by being very close. ([#0607](<https://discord.com/channels/939956361977020449/1421716546300018800>))
* Fixed the hitboxes of the large trees in topside tartarus, curie park, and near corporate offices.
