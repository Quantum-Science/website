QSERF v3.6.4 is the fourth patch following [v3.6.0](/wiki/updates/qserf/v3.6.0), fixing various issues.

## Additions
* Added a placeholder combat line in Sublevel-1.
* Added the “Eyelander” sword from the Santa Soupcan Event, accessible via the `give` command.

## Changes
* Combatives can no longer participate in Server Ending Votes.
* Packaged the accessory locker model and made it atomic.
* Removed the Private Server restrictions for all Event Weapons and the `G-TEST`.

## Fixes
* Fixed a bug where the Security Tour Lever would permanently brick after being used.
* Fixed a bug where the Security Tour & Training Levers would place Raiders on the Employee team regardless of their group status.
* Fixed a security vulnerability in the weapons system.
