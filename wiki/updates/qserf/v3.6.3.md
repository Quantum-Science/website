QSERF v3.6.3 is the third patch following [v3.6.0](/wiki/updates/qserf/v3.6.0), ending [April Fools 2025](/wiki/updates/qserf/april_fools_25) and fixing various issues.

## Changes
* April Fools has come to a close!
* Updated Keycard Reader security check to use `get_team_players`.
* Updated `append_player_to_team` function to check if the player is already on the target team.
* Removed unneeded `reset_keycard_reader` lines in the Tartarus Seal and Warhead.

## Fixes
* Fixed a thread memory leak in Keycard Readers.
* Fixed a bug where Keycard Readers under the Tartarus Seal or Warhead could become unhackable after regen. (Reports: [#0302](<https://discord.com/channels/939956361977020449/1352212146355961923>), [#0305](<https://discord.com/channels/939956361977020449/1352489879111471125>))
* Fixed a bug where Avatar Item Givers didn't account for pass transfers.
* Fixed a typo in the notification for when you walk away from a conversation. (Report: [#0328](<https://discord.com/channels/939956361977020449/1355878432130597024>))
* Radiation in the DMR Chamber no longer deals damage on the lowest intensity.
* Fixed Vector-45 textures.
* Fixed text chat tag for Developers.

### v3.6.3b
* Corrected the initial ambient lighting.
* Fixed QDF's server vote command.
* Fixed a security vulnerability in the Admin Tool Dispenser.
* Fixed an unintended permission error with the `give` command in relation to weapons.
