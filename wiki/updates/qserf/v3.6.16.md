QSERF v3.6.16 is the sixteenth patch following [v3.6.0](/wiki/updates/qserf/v3.6.0), which fixes various issues.

## Changes
* The DMR's fuel, integrity, and temperature checks no longer run during meltdown.

## Fixes
* Fixed a bug where phase 3 of meltdown had a 3 in 50 chance to just simply give up.
* Fixed a bug where the DMR could enter maintenance during meltdown if you did some really utterly specific things.
* Added safety checks to each phase of meltdown to make sure no part of the sequence is already active.
* Heavily optimised the Black Hole's server code.
