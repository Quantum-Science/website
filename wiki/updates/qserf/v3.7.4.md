QSERF v3.7.4 is the fourth patch following [v3.7.0](/wiki/updates/qserf/v3.7.0), fixing various issues.

## Changes
* Improved performance of the DMR when moving, seeing up to ~16% in frame time improvements.

## Fixes
* Fixed a bug where bullets went through NPCs.
* Fixed a bug where the key turning audio had a messed up range in most instances. ([#0733](<https://discord.com/channels/939956361977020449/1448804492090019981>))
* Disabled acoustic simulation when it shouldn't have been enabled, though this only affects studio as the feature is still in studio beta.
