QSERF v3.6.21 is the twenty-first patch following [v3.6.0](/wiki/updates/qserf/v3.6.0), fixing various issues.

## Additions
* The jumping cooldown has been added back, and now starts when you land instead.
  * `0.6s/600ms` for combatives, and `0.2s/200ms` for everyone else.

## Changes
* Changed `Workspace.ModelStreamingMode` back to `Improved` as [we've been given word](<https://devforum.roblox.com/t/avatars-going-invisible-and-falling-apart-due-to-streamingenabled/3983450/28?u=katsumisoda>) that the bug we tackled previously has been resolved, if you see any symptoms of [#0626](<https://discord.com/channels/939956361977020449/1425108440925077646>) please @mention me immediately. ([#0626](<https://discord.com/channels/939956361977020449/1425108440925077646>), [#0667](<https://discord.com/channels/939956361977020449/1433291644207104182>))
* Optimised the meshes of supposedly high comedic value inside the Wonkavator.
* Removed the `OwO Cat` admin item.

## Fixes
* Fixed a bug with WebStoreService's flush store code that has been very rarely causing data loss.
* Fixed a bug with the Jetpack where you could boost yourself by jumping on something mid-flight.
* Fixed a bug where you could fly out of bounds using the Jetpack in certain areas. ([#0469](<https://discord.com/channels/939956361977020449/1386768505684361437>), [#0659](<https://discord.com/channels/939956361977020449/1431688331024007178>))
* Fixed a bug where the Tartarus Seal's cycling sequence would persist through server regen. ([#0562](<https://discord.com/channels/939956361977020449/1407054410177052823>))
* Fixed a bug where the game would initially start in "full-bright". ([#0675](<https://discord.com/channels/939956361977020449/1434261973805039766>))
* Fixed a bug where one of the segments on the date boards had the wrong colour. ([#0670](<https://discord.com/channels/939956361977020449/1434131602207932416>))
* Fixed a bug where three date boards were non-functional. ([#0676](<https://discord.com/channels/939956361977020449/1434445338596347964>))
* Fixed a bug where the warhead display in the raider spawn wouldn't display text correctly. ([#0674](<https://discord.com/channels/939956361977020449/1434245337064804492>))
* Fixed a bug where the part used to detect when your camera is underwater could be destroyed by the void. ([#0662](<https://discord.com/channels/939956361977020449/1431951734896590868>))
* Fixed a bug where interacting with John Freeman could brick the dialogue system. ([#0593](<https://discord.com/channels/939956361977020449/1415715741575155742>))
* Fixed an issue where Hugh Neutron in the Wonkavator was partially visible in one of the DMRCR's rooms. ([#0672](<https://discord.com/channels/939956361977020449/1434234929042161844>))
