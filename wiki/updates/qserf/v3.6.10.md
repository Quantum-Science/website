QSERF v3.6.10 is the tenth patch following [v3.6.0](/wiki/updates/qserf/v3.6.0), which fixes various issues.

## Additions
* Button Logs will now show all logs that have been submitted for the entire server's lifetime.

## Changes
* Disabled the Guardsman help button and join message.
* Guardsman now stores up to 1000 text chat logs (previously 500) to assist moderation.
* Ported over new API Manager.
* Raider bans now display their time remaining.
* Supervisory no longer has access to the administration team, and the regular requirement level has been fixed.
* Updated the raider rules.
* Your account is now required to be at least 5 days old to join the experience.

## Fixes
* Fixed a bug where raider bans wouldn't expire if the player happened to be in-game at the same time until they rejoined.
* Fixed a memory leak relating to client lighting effects.
* Fixed John Freeman having a duplicate dialogue option. ([#0552](<https://discord.com/channels/939956361977020449/1404909078643343452>))
* Fixed a bug where player ground offset kept dying. Definitively. ([#0500](<https://discord.com/channels/939956361977020449/1397182009880608832>))
* Fixed a bug where payouts would only be given if the player **hadn't** moved since the last payout.
* Fixed a bug where the raider agreement would only display *after* you left the team.
* Removed the `with_metadata` tag from decorative keycard readers which was causing errors.
