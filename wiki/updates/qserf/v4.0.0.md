QSERF v4.0.0, the release of the Maintenance Update, is an upcoming update expected to release in 2026.

## Additions
* Added various facility tasks, which pop up every now and then, that can be completed by the maintenance team.
* Added a pager that replaces the old bottom-right notifications.
* Added a new area called "Millikan Cavern".
* Added a new successful shutdown track composed by @JalventScientist.
* Added a secret alternative track for meltdown phase 1 that plays during overtime work.
* Added a vending machine to topside tartarus, outside the visitor's center.
* Added an over-the-shoulder camera for controller/mobile players to improve gameplay.
* Added an overlay for security operatives that displays their current patrol progress, if one is active.
* Added debug panels for audio & client, `Shift + F6` and `Shift + F7` respectively.
* Added a small statistics interface in the top-left corner displaying stuff like framerate & latency, will be improved over time, can be toggled with `Shift + F12` or `Fn + Shift + F12`.
* Added a security camera desk in Control Station 47. (#S0721)
* Added a visual notice and timer for server restarts.
* Added a `cmdr` command to show the Cmdr interface from the text chat.
* Added a `mod` command to toggle the moderator text chat tag.
* Added a welcome message to the Cmdr interface.
* Added emergency lighting in raider spawn. (#S0791)
* Added some new voicelines to the F.A.A.S.
* Added alarm lights in Sublevel-4.
* Improved internal data analytics.
* Overhauled Control Station 15.
* Overhauled the bottomside tartarus control room.
* Overhauled Sublevel-1 & Sublevel-2.
* Redesigned the loading screen and title screen, with improved UI & UX.
	* Tip: You can now skip the intro sequence by pressing space on a keyboard, or the A button on controllers.
* Redesigned the raider guidelines user interface.
* Reintroduced combative hazmat suit colours, to make them visually distinct from other players.
* Reintroduced damage direction indicators for bullets. (TODO: verify this wasn't devsite exclusive, check mainsite)
* The mouse can now be unlocked in first-person by holding Alt/Option.
* The reduce motion setting now applies to various user interfaces.
* The select button on controllers now opens the user menu.
* The server region is now displayed in private servers. (#S0733)
* When game data fails to load, the issue will now be properly communicated to the player.
* You can now walk while using the walk emote. (#S0346)
* Clicking on the game version & server name in the menu will now provide additional information.
* Weapon inspect animations can now be "paused" by holding the inspect key. (#S0612)
* Keycard Readers will now show a group membership prompt when used by visitors.
* Servers with a pending restart will now move players to a new server after the nightshift has ended.
* *(...and more to follow)*

## Changes
* Combatives can no longer wear any event hazmat suits.
* Converted various transparent textures into materials.
* Employees can no longer be harmed by frag grenades. (#S0484)
* Game commands are now available in text chat and the Guardsman command box.
* Hazmat suits now hide layered clothing when equipped.
* Improved the alarm light models, with a new caged variant for industrial areas.
* Improved the FBM JX models with updated textures.
* Improved controller navigation for the user menu.
* Improved grenade & rocket projectile physics.
* Improved player ragdolls. (TODO: verify what this actually means)
* Improved some of the grammar in team descriptions.
* Improved weapon equipping by reducing visual issues, and introducing a visual equip timer.
* Improved visibility of the user menu on mobile devices.
* Introduced more employee-maintenance doors across the facility.
* Many significant performance improvements across the board.
* Player rank tags are now hidden when they die.
* Players now always collide with push doors, regardless of whether or not they're open.
* Players using the raider day pass will now be notified of their time remaining when joining the team. (#S0536)
* Rebalanced the dash coil, and made it so you can only dash while moving. (#S0686)
* Rebalanced various sound effects across the game to improve the audio experience.
* Reduced the push door interaction cooldown.
* Reduced the push door interaction distance from 24 to 18.
* Removed flamethrower hurt animation.
* Revamped object interactions with improved visuals.
* Revamped NPC interactions with new visuals and improved dialogue.
* Removed MGKS stains as they have been visually broken for the longest time.
* Removed the QWN rank tag icon.
* Removed the WCS Device.
* Removed zombie run & walk from the combative animation whitelist.
* Rewrote most of the codebase to better support new features and any long-term goals.
* Screenshot captures will no longer hide certain UI. (TODO: figure out what this actually means)
* Sound effects now use audio ducking when any “important” music is playing.
	* Essentially, this improves the audio experience by lowering the volume of the world when any important music is playing (meltdown, warhead, etc.), however this does not affect the F.A.A.S.
* Staff members are now granted certain passes for free, to keep!
* The Biden Tree, Jetpack, Obama Tree, and Riot Shield now only use SST-owned animations.
* The character can no longer turn while dashing.
* The coffee item no longer has the ability to spit out when drinking.
* The DMRCR's alarm panel is now permanently disabled during meltdown.
* The user menu will now close when switching teams.
* The pages on the user menu now reset their scroll position when switching between them.
* The sliding door lever now resets on regen, and its requirement has been changed to only require the player to be on the security team. (TODO: check if this was done in mainsite)
* The vhs overlay now extends to cover wider screens.
* The walk emote now makes you move slowly.
* Updated administrator portraits in the supervisor room.
* Updated old assets in administrator control stations.
* Updated the clipboard item model.
* Updated the warhead keycard reader to visually use the correct team variant.
* *(...and more to follow)*

## Fixes
* Fixed a bug where attachments created for riot shield impact effects were not destroyed.
* Fixed a bug where the character would get stuck in the landing state when entering anti-gravity at the same. (TODO: check if this affected mainsite)
* Fixed a bug where the data heist escapee ending could error.
* Fixed a bug where the `ranktag` command couldn't re-enable rank icons. (#R0740)
* Fixed a bug where the warhead often couldn't be heard outside Sublevel-4.
* Fixed a security vulnerability with the overseer guardian head.
* Fixed a typo in the name of the Icy Spear item.
* Fixed animation blending issues on various items.
* Fixed the hazmat suit collar transition being attached to the wrong body part.
* Fixed various warhead timers going for one second longer than they should.
* *(...and more to follow)*

## Trivia
* This update has been in-development since early 2025, and is planned to be the final large content update.
* This update is the first version to increase the major version number in several years, and is the first major content update since the [Tartarus Update](/wiki/updates/qserf/v3.5.0).
* The new successful shutdown track was originally intended to release in the [Tartarus Update](/wiki/updates/qserf/v3.5.0).
