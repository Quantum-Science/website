**4.0.0**, the release of the [Maintenance Update](/wiki/maintenance_update), is an upcoming [QSERF](/wiki/qserf) update expected to release in 2026.

## Additions
* Added various facility tasks, which pop up every now and then, that can be completed by the maintenance team.
* Added a pager that replaces the old bottom-right notifications.
* Added a new area called "Millikan Cavern".
* Added a new successful shutdown track.
* Added a secret alternative track for meltdown phase 1 that plays during overtime work.
* Added a vending machine to Control Station 47.
* Overhauled the conversation experience for NPCs.
* Overhauled the music track for meltdown phase 1.
* Reintroduced combative hazmat suit colours, to make them visually distinct from other players.
* ***...and more to be announced at a later date!***

## Changes
* Adjusted the post-processing effects of the P.A System.
* Combatives can no longer wear any event hazmat suits.
* Elevator travel time now depends on vertical distance, instead of overall distance.
* Game commands are now available in text chat and the Guardsman command box.
* Hazmat suits now hide layered clothing when equipped.
* Improved controller navigation for the user menu.
* Improved weapon equipping by reducing visual issues, and introducing a visual equip timer.
* Introduced more employee-maintenance doors across the facility.
* Many significant performance improvements across the board.
* Rebalanced various sound effects across the game to improve the audio experience.
* Revamped object interactions with improved visuals.
* Rewrote most of the codebase to better support new features and any long-term goals.
* Sound effects now use audio ducking when any “important” music is playing.
	* Essentially, this improves the audio experience by lowering the volume of the world when any important music is playing (meltdown, warhead, etc.), however this does not affect the F.A.A.S.
* The coffee item no longer has the ability to spit out when drinking.
* ***...and more to be announced at a later date!***

## Fixes
* Added border extensions to the VHS Overlay, which fixes a visual gap on particularly wide/tall displays.
* Improved the timer logic for thrown grenades, making timings more consistent.
* Fixed a bug where frame spikes would massively increase weapon recoil.
* Fixed a bug where the warhead often couldn't be heard outside Sublevel-4.
* Fixed a bug where weapon magazines had collisions with characters.
* Fixed momentum preservation for character platforms.
* Fixed randomised meltdown destruction having a ~25% chance to not occur.
* Fixed the Boxing Gloves, Crucible, Frying Pan (melee), Ice Spear, Military Axe, Overseer Axe, and XLS Mark II.
* Fixed the hazmat suit collar transition being attached to the wrong body part.
* Fixed various warhead timers going for one second longer than they should.
* The nightshift no longer modifies `Lighting.ClockTime`, which effectively changed the brightness of the game as the shift progressed.
* ***...and more to be announced at a later date!***

## Trivia
* This update has been in-development since early 2025, and is planned to be the final large content update.
* This update is the first version to increase the major version number in several years, and is the first major content update since the [Tartarus Update](/wiki/qserf_3.5.0).
* The new successful shutdown track was originally intended to release in the [Tartarus Update](/wiki/qserf_3.5.0).
