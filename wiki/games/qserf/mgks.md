**Modular Gun Kit System (MGKS)** is the weapons system developed by the [Quantum Structural Science Team](/wiki/groups/qsst) that is used in and designed for [QSERF](/wiki/games/qserf).

## History
The system was originally developed to supersede the previous system, which was a version of NoCol heavily modified by TreencyToo.

### Version 1
**Modular Gun Kit System V1 (MGKS1)** was developed by AdjacentPhoenix as a rewritten version of NoCol following community drama that lead to the creators of NoCol banning the system from QSERF. It was considered a temporary replacement that was shortly followed up by MGKS2.

### Version 2
**Modular Gun Kit System V2 (MGKS2)** was originally solely developed by TreencyToo, and first released in 2022 with a public beta test. It remains the system currently used in QSERF, and has received several major improvements over the following years.

## Trivia
* The weapon configuration interface intended for developers can be opened in private servers using the `mgks_editor` command.
