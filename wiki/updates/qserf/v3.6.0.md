THE UPDATE

## Additions
* **New Clothing & Hard Hats!!** As seen on the Avatar Marketplace!
* **New Combat Armour!** Now with speed debuffs.
* Added a new mailing office within the DMR Control Room!
* Added a new *secret* badge called **Overtime Work**, only obtainable in **public servers**.
* Added a new object interaction system, with object details, cool UI, and mobile support!
* Added a new hanging TV in certain rooms.
* Added two new unique posters!
* Added new clothing for Security.
* Added first-person zoom function via the right mouse button, can be turned off.
* Added a new “simple” option for camera shaking.
* Added portrait for group photo from December 2024.
* Added a speaker in Sublevel-2.
* Refreshed the changing area lockers.
* Refreshed the TV model.
* Introduced new weapon limits:
  * AA-12, 3 per team.
  * M60, 2 per team.
  * RPD, 2 per team.
  * RPG-7, 1 per team.
  * Saiga-12, 3 per team.
* Readded quests for Admin Warhead events.
* The event hazmat suits have returned!
* Crouching now has reduced recoil for certain firearms.
* When Foxtrot-9 blows up, the crane is now pushed by the explosion.
* Various weapons now have their own equip time, with the new default being `0.5` seconds.
* The DMR Chamber radiation indicator now errors when above `9999` roentgen.
* The DMR Chamber radiation indicator now slowly decreases during a Phase 2 Shutdown.
* Props within Control Station 47 are now fully affected by the black hole.
* Various animation packs are now allowed on combative teams.
* Various commands are now available to private servers owners in the F2 console.
* QSERF Avatar Items are now recognised as in-experience items, allowing you to switch hats!
